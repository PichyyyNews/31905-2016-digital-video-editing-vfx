## 🎬 หัวใจสำคัญของกระบวนการผลิตสื่อดิจิทัล (The 3P Workflow)

```mermaid
flowchart LR
    A["1. Pre-production<br/><b>(คิด & วางแผนบนกระดาษ)</b><br/>บท · สตอรีบอร์ด · คิวงาน"] --> B["2. Production<br/><b>(ลงมือถ่ายทำตามแผน)</b><br/>กล้อง · แสง · เสียง · สำรองไฟล์"]
    B --> C["3. Post-production<br/><b>(ตัดต่อ & ปรุงแต่ง)</b><br/>ตัดต่อ · เสียง · สี · VFX · Export"]
```

> [!TIP] จำง่ายใน 1 ประโยค
> **"Pre คือวางแผนบนกระดาษ $\rightarrow$ Pro คือออกไปถ่ายทำ $\rightarrow$ Post คือนำมาตัดต่อให้สมบูรณ์"**

## 👨‍🏫 บุคลากรผู้รับผิดชอบรายวิชา
